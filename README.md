# rkeb.github.io

Personal website and CV of Rachel K. E. Bellamy, Ph.D.

Plain HTML and CSS; no build step. GitHub Pages serves it from the `main` branch.

- `index.html` — home page
- `cv.html` — full CV (print-friendly)
- `Rachel_Bellamy_CV.pdf` — CV download (regenerate by printing `cv.html` to PDF)
- `style.css` — shared styles
